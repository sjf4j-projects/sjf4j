## Validation results

**Lower is better.** `±` is JMH's reported 99.9% score error, not the fork-mean standard deviation.

| Input | Implementation / method | Mean (µs/op) | JMH error (± µs/op) | Allocation (B/op) |
| --- | --- | ---: | ---: | ---: |
| POJO | `pojo_isValid_runtime` | 3.107 | 0.120 | 2120.054 |
| POJO | `pojo_isValid_compiled` | **0.058** | 0.001 | ≈ 0 |
| Map | `map_isValid_runtime` | 2.295 | 0.061 | 808.040 |
| Map | `map_isValid_compiled` | **0.992** | 0.030 | 144.017 |
| Jackson2 JsonNode | `jsonNode_isValid_runtime` | **4.051** | 0.130 | 853.404 |
| Jackson2 JsonNode | `jsonNode_isValid_networknt` | 9.758 | 0.263 | 23864.172 |

- POJO Compiled vs SJF4J Runtime: `3.107 / 0.058 ≈ 53.6×` throughput-equivalent speedup, based on rounded reported latencies.
- Map Compiled vs SJF4J Runtime: `2.295 / 0.992 ≈ 2.31×` speedup.
- **Same Jackson2 JsonNode:** SJF4J Runtime vs NetworkNT 2.0.5: `9.758 / 4.051 ≈ 2.41×` speedup, with ~96.4% lower measured allocation.
- Do **not** compare POJO or Map validator scores to NetworkNT as if they operated on equivalent representations.

## Roundtrip results

Roundtrip includes serialization **and** deserialization of the Creek model. The baseline Jackson2 roundtrip **does not validate**.

| Method | Mean (µs/op) | JMH error (± µs/op) | Allocation (B/op) |
| --- | ---: | ---: | ---: |
| `roundtrip_jackson` | 7.024 | 0.322 | 7696.123 |
| `roundtrip_compiled` | **5.829** | 0.316 | 6824.102 |
| `roundtrip_isValid_runtime` | 10.779 | 0.560 | 9816.190 |
| `roundtrip_isValid_compiled` | **5.888** | 0.294 | 6824.104 |

**Primary KPI:** `roundtrip_jackson / roundtrip_isValid_compiled = 7.024 / 5.888 ≈ 1.193×`.
The compiled **binding + validation** pipeline was ~16.2% lower latency and ~11.3% lower allocation than Jackson2 **binding alone** in this run.

The observed difference between `roundtrip_compiled` and `roundtrip_isValid_compiled` was only 0.059 µs/op, smaller than the measurement uncertainty; this is **not** a direct isolated measurement of validator cost.
