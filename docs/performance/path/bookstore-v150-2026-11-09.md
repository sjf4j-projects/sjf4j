# Bookstore JSONPath Benchmark — SJF4J v1.5.0 — 2026-11-09

Historical performance snapshot. Preserve this report unchanged when recording later versions.

## Provenance

- **Run:** [Path Full Benchmark #42601902947](https://github.com/sjf4j-projects/sjf4j/actions/runs/42601902947) — successful Full / Map, JsonNode, POJO, and Parse jobs
- **Source commit:** [`17844a4320854d6cdb970b21da20e6d97d2664fe`](https://github.com/sjf4j-projects/sjf4j/commit/17844a4320854d6cdb970b21da20e6d97d2664fe)
- **Date:** 2026-11-09 UTC
- **JDK / runner:** Temurin OpenJDK 25.0.5+8, Ubuntu 24.04, x86-64 GitHub-hosted runners
- **CPU:** Map/JsonNode jobs: AMD EPYC 7763; POJO/Parse jobs: AMD EPYC 9V74. Do not compare absolute latencies across these independent runner types.
- **JMH:** AverageTime, 1 thread, 3 forks, 5 × 1s warmup, 5 × 1s measurement, `-prof gc`
- **Input:** deterministic Bookstore object with 12 / 123 / 1,229 books. Actual JSON sizes: **1,021 / 10,267 / 102,395 bytes** (nominal 1/10/100KB); ~30% of records match the filter
- **Semantics:** Query inputs and expressions are prebuilt; query timing excludes parsing/compilation. Results are checked for equality in setup. The Parse group measures expression compilation only.
- **Case count:** 33 Map + 30 JsonNode + 30 POJO + 14 Parse = **107** completed cases
- **Raw artifacts:** [Full combined report, 107 JMH cases, original fork measurements and allocation data](https://github.com/sjf4j-projects/sjf4j/actions/runs/42601902947/artifacts/13667915594) (30-day retention; link can expire)

**All query time figures below are Best 2 Mean in ns/op; lower is better.** For each exact benchmark case, average the five measurements within each fork, exclude that case's slowest fork, and average the other two. Speedup = baseline Best 2 Mean / candidate Best 2 Mean. The original JMH mean and score error are **not** Best 2 Mean uncertainty estimates. Values are rounded for display; speedup ratios use full precision.

## Fork stability

Three cases had a slowest fork more than 15% above the fastest fork, even though all 107 cases completed. Figures are the three **independent fork means** in ns/op, before Best 2 selection.

| Case | Fork 1 | Fork 2 | Fork 3 |
| --- | ---: | ---: | ---: |
| Map / 100KB / Direct / Runtime | 51.4 | 52.3 | 70.9 |
| JsonNode / 100KB / Wildcard / Jayway | 300,989.5 | 349,010.0 | 314,763.7 |
| Parse / `$..price` / SJF4J | 36.4 | 63.8 | 36.5 |

Best 2 Mean deliberately emphasizes the faster JVM executions and must not be read as the expected performance of an arbitrary fork. Recheck these unstable cases before using small differences to claim regressions.

## Interpretation and reuse

- All claims are **specific to this Bookstore workload**, Java version, JMH settings, and GitHub-hosted machines.
- Compare implementations within the same input type and job; do not compare POJO absolute timings to Map/JsonNode to claim relative backend efficiency.
- Query expression parsing, JSON document parsing, mutation, and validation are different workloads. They are not included in the Query results.
- Preserve the full raw JMH JSON separately when reproducing or extending the benchmark. GitHub Actions artifacts expire; this versioned Markdown retains the complete **Best 2 latency matrix** (107 cases) and representative allocation/fork evidence.
