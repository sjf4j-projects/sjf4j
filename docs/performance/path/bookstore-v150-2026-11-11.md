# Bookstore JSONPath Benchmark — SJF4J v1.5.0 — 2026-11-11

Versioned performance snapshot. Preserve this report unchanged when recording later runs.

## Provenance

- **Run:** [Path Full Benchmark #42960489260](https://github.com/sjf4j-projects/sjf4j/actions/runs/42960489260) — successful Full / Map, JsonNode, POJO, and Parse jobs.
- **Source commit:** [`148b26e881d6fad2fcb2a06684a779c0880c6baf`](https://github.com/sjf4j-projects/sjf4j/commit/148b26e881d6fad2fcb2a06684a779c0880c6baf)
- **Comparison dependency versions (at the source commit):** Jayway JsonPath `3.0.0`; Jackson2 Databind `2.22.3` for the JsonNode workload.
- **Date:** 2026-11-11 UTC.
- **JDK / OS:** Temurin OpenJDK 25.0.5+8, Ubuntu 24.04, x86-64 GitHub-hosted runners.
- **CPU:** Map/POJO/Parse — AMD EPYC 7763; JsonNode — AMD EPYC 9V74. Absolute latencies from different runner CPU models should not be compared.
- **JMH:** AverageTime, 1 thread, 3 independent forks, 5 × 1s warmup and 5 × 1s measurement, `-prof gc`.
- **Inputs:** deterministic Bookstore object: **1,021 / 10,267 / 102,395 bytes** (12 / 123 / 1,229 books), ~30% Filter matches.
- **Semantics:** query input objects and paths are prepared outside timed operations, with setup-time result-equivalence checks. The Parse group measures only expression compilation.
- **Completed:** 45 Map + 45 JsonNode + 30 POJO + 14 Parse = **134 JMH cases**.
- **Raw artifacts:** [combined and per-shape JMH JSON, logs, and runner metadata](https://github.com/sjf4j-projects/sjf4j/actions/runs/42960489260#artifacts) (subject to GitHub's retention period).

**All query latency values below are Best 2 Mean in ns/op (lower is better).** For each exact method/size case, average the five iterations in each of three forks, exclude the slowest fork independently, then average the other two. Ratios divide baseline by candidate. The untrimmed JMH score/error and B/op must not be interpreted as Best 2 Mean uncertainty estimates.

## Interpretation

- For the same pre-parsed Map and JsonNode documents, Runtime beats Jayway in **30/30** comparable query cases; Compiled beats Runtime in **45/45** comparable cases over Map, JsonNode, and POJO.
- All five query types now generate compiled traversal for Map, JsonNode, and POJO. Filter predicates use cached `FilterExpr`; Descendant uses generated recursion without full-path Runtime fallback.
- This snapshot represents one Bookstore workload on shared GitHub-hosted CPUs. Smaller speedups may be affected by fork variability.
- Expression parsing, JSON document parsing, JSON mutation, and schema validation are different workloads. The Parse group only measures query expression compilation.
